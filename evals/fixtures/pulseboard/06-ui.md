# PulseBoard — UI Design System

### 1. Visual Identity & Tone

Visual tokens embody a minimalist, high-contrast, utilitarian aesthetic with deep slate surfaces, crisp high-contrast typography, and semantic emerald/amber/crimson status pills.

### 2. Design Tokens

Built on Tailwind CSS v4 with CSS custom properties: primary `#2563EB`, secondary `#111827`, background `#0B1120`, text `#F8FAFC`, semantic status colors (`#16A34A`, `#D97706`, `#DC2626`), Inter for headings/body, JetBrains Mono for tabular metrics, and `6px` base border radius.

### 3. Component Styling

Buttons, form inputs, drawers, and status cards define explicit default, hover, focus-visible ring, disabled, and error states meeting WCAG 2.1 AA contrast.
