# PulseBoard — UX Architecture

### 1. Information Architecture

Information architecture centers on four high-signal surfaces linked via a compact top navigation bar with workspace switcher: Admin Monitor Dashboard, Create/Edit Monitor Drawer, Incident Detail & Timeline, and Public Status Page.

### 2. Core User Journeys

- From the Admin Monitor Dashboard, engineering leads open the Create/Edit Monitor Drawer, run a one-click Test Probe before saving, and filter operational vs. failing monitors via keyboard-accessible filter pills.
- Selecting an active incident opens Incident Detail & Timeline to post inline timestamped updates, immediately reflected on the Public Status Page.

### 3. Screen Wireframes

Each screen exposes semantic landmarks (`header`, `nav`, `main`), WCAG 2.1 AA contrast, full keyboard navigation, and status indicators pairing color with explicit text labels and icons.
