# PulseBoard — UX Architecture

Information architecture centers on three high-signal views: Admin Monitor Dashboard, Incident Timeline Editor, and Public Status Page, linked via a compact top navigation bar.

## Accessibility & Interactions

All status states pair color with explicit text labels and semantic ARIA landmarks so color-blind users and screen readers interpret service health unambiguously.
